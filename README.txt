iPhone / iPad app (PWA) - free, no App Store needed
1. Naya GitHub repo banayen aur is folder ki sari files (.github samet) upload karein.
2. Repo > Settings > Pages > Source = "GitHub Actions" chunen.
3. Actions me "Deploy to GitHub Pages" chalne den. Khatam hone par link milega: https://USERNAME.github.io/REPO/
4. iPhone par Safari me wo link kholen > Share > "Add to Home Screen". Ab ye icon se app ki tarah khulega.
Update: index.html badal kar push karein. (Repo public rakhna parta hai agar Pages free plan par ho.)
